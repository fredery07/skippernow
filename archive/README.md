# Archive

Ce dossier contient d'anciens fichiers de travail retrouvés à la racine du
dépôt (copies de sauvegarde de `index.html`, brouillons de formulaire,
archives ZIP). Ils ne font pas partie du site en production :

- ils ne sont référencés par aucune page, ni par `sitemap.xml`, ni par un
  script de génération ;
- `robots.txt` (à la racine) interdit leur indexation (`Disallow: /archive/`) ;
- `analytics.js` ignore explicitement ces noms de fichiers si jamais l'un
  d'eux est ouvert directement.

Fichiers déplacés ici le 3 septembre 2026 (lors de la correction des
problèmes analytics/réservation du même jour) :

- `index (1).html`, `index (2).html`, `index (4).html` — copies de
  sauvegarde de `index.html`, générées automatiquement par le navigateur
  lors de téléchargements successifs.
- `index-formulaire-simple.html`, `index-services.html` — brouillons de
  travail antérieurs à la version actuelle du formulaire de réservation.
- `MISE-A-JOUR-VILLES.zip`, `skippernow-visiteurs-mondial.zip` — archives
  de travail.

Si ces fichiers ne sont plus utiles, ce dossier peut être supprimé sans
impact sur le site.
